# 外部调研：薯条加热玩法与数据基准（2026-09-10 网络调研）
## 一、薯条基本盘（官方规则）
- 定位：官方内容加热工具，按**曝光**计费（类似抖音Dou+）；与聚光（广告平台，2000元起充、按点击/互动计费）分工不同
- 门槛：无粉丝限制；**最低750薯币（约75-108元）起投**；仅能投**近90天内发布**的笔记
- 2026年新规（薯条服务协议 2026-07-01版）：
  - 非营销内容+浅层目标（点赞收藏）→ 可直接投
  - **营销内容或深度目标（私信咨询量等）→ 需账号升级后才能投**
  - 平台会预判内容是否含营销属性，判断有误时有权中止服务
  - 下单后不可修改，已支付不退款；消耗后才可开票（单张发票上限1万元）
- 三种推广目标：阅读/播放量（要曝光）、点赞收藏量（要互动）、粉丝关注量（要粉丝）
- 定向：智能推荐（20+兴趣标签）或自定义（性别/年龄/地域/兴趣偏好）
- 时长：6/12/24小时；<300元建议6小时集中曝光；300-1000元12小时；>1000元24小时

## 二、该不该投（社区共识）
- **薯条是放大器不是发动机**：只加热"自然流量已被验证"的笔记，救不活没人看的笔记
- 判断基准看**自己账号历史中位数**，不是网上通用标准
- 发布后24小时内，互动数据明显高于过往笔记 → 值得加热（进入降温期时加热续命）
- 新手/新号先别投：钱花在多测试内容上更划算；出现第一条超均值笔记再小额放大
- 涨粉目标前提：笔记里要有"关注理由"（干货型有、随手拍没有）
- 加热人群画像若与自然流量不符，会干扰后续自然分发——投完要看"涨的是不是对的人"

## 三、投放节奏与金额（主流玩法）
- 小额多单：750×3单 优于 3000×1单（方便调整、总效果更好）
- 测试单：75-150元×6小时，测内容潜力（点击率）
- 冷启动：粉丝关注量模式，750-1500薯条/次，每日分时段多投
- 爆款助推：识别自然流量优质笔记（24h互动量超账号均值50%），阅读量模式延长热度
- A/B测试：同主题不同封面各投750，对比点击率；同封面不同人群包对比
- 时段：投6小时选 早8-14 / 午12-18 / 晚18-24 三个窗口之一；避开凌晨
- 单粉成本：优质内容+精准定向可做到0.3-1元（泛内容会到3-5元甚至更高，<5元为可接受参考线）

## 四、数据基准（社区+官方参考）
- 封面点击率：<5%先优化封面再投；>8%为优秀（发现页流量撬动线）
- 互动率：>5%合格（点赞+收藏+评论/阅读）
- 视频完播率：>25-30%合格；图文阅读完成率>50%
- CES = 赞1+藏1+评4+转发4+关8；评论/转发/关注权重远高于赞藏
- 爆文线（通用粗口径）：小眼睛(阅读)≥5万 或 互动率≥5% 且持续3天以上；更多用"自身历史中位数对比法"
- 2024年起后台新增【自然流量对比】模块，可看薯条带来的真实增量
- 深度转化链路数据需：粉丝≥1000+原创≥10篇+绑定企业号才完整可见

## 五、审核红线（与辅具行业强相关）
- 薯条严格禁商业营销内容（广告标/赞助标/引导购买/联系方式）→ 挂车笔记、报备商单走蒲公英/聚光
- 医疗器械相关：功效承诺（根治/治疗/100%有效）、医疗用语是审核驳回高发区；轮椅/助行器属器械类目，文案必须生活场景化、禁疗效承诺
- 2026年AI审核收紧：纯产品说明书式内容、伪素人种草、同质化搬运、站外引流=限流重点
- 合规写法：7分真实体验+3分产品；"亲测/个人体感"替代绝对化用语；站内闭环

## 六、银发人群与老年辅具在小红书的机会
- 小红书60岁+月活已超3000万（2024底，官方口径），"老红书"现象级出圈；60%来自二线及以下城市
- 银发博主活跃粉丝占比极高（梅英阿嬷98%、周大爷70%），粉丝含金量高
- 平台已发布《老年人友好使用手册》，官方在推动银发生态
- 适老改造、出门在外互助父母计划等助老话题成为热词；年轻人替父母搜索/决策是主流路径（"子女代际搜索"）
- 结论：轮椅/助行器内容在小红书有真实人群（既有老人自己，更是35-55岁子女），加热应主投"成年子女"人群包

## 七、对本公司加热规划的直接启示（初步）
1. 加热只挑"自然跑出来的前20%"笔记——定一条客观晋级线（如互动率超自身中位数1.5倍）
2. 三段式预算：测试（75-150元×6h）→ 加热（750-1500）→ 爆款续命（多单接力），拒绝一步到位大单
3. 主投目标用"点赞收藏"（喂CES）+ 关键笔记用"涨粉"（账号冷启动期）
4. 人群包优先"成年子女/中老年/家庭健康"兴趣，A/B测试智能推荐 vs 自定义
5. 内容结构规避器械红线：场景故事+使用技巧为主，产品卖点弱植入，无疗效承诺
6. 建立《薯条投放台账》：每单记录（金额/时长/人群包/时段/点击率/互动率/涨粉/单粉成本），两周一次复盘调参
7. 加热与发布时序绑定：发布后1-2小时内首投抢占初始流量窗口（课件口径）
8. 封面点击率<5%的笔记一律先改封面再加热（课件红线）

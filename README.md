## 投放执行框架

```
候选筛选 → 投放测试 → 数据监测 → 优化加投
```

| 环节 | 判定标准 |
|---|---|
| 候选筛选 | 发布 ≤90 天、视频优先、含关键词、无违规 |
| 投放测试 | A 池 600 元开测，分笔记独立追踪 |
| 数据监测 | 曝光 / 点击率 / 互动成本，对照 CPM≈9.6 元基准线 |
| 优化加投 | 跑赢基准线的笔记追加预算，低于判定线停止 |
